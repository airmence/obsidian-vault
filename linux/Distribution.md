## Definition of a Linux Distribution

A Linux distribution, commonly referred to as a "distro," is a complete operating system that is built around the Linux kernel. It includes various software packages, system libraries, and a package management system, which together create a user-friendly computing environment.

## Key Components of a Linux Distribution

### Core Elements

- Linux Kernel: The core component that manages hardware and system resources.
- System Libraries: Essential libraries, such as the GNU C Library, that provide functions for applications.
- User Interface: Can be graphical (like GNOME or KDE) or command-line based, allowing user interaction with the system.
- Software Packages: A collection of applications and utilities, including productivity tools, web browsers, and development software.
- Package Management System: Tools for installing, updating, and removing software packages (e.g., APT for Debian-based distros, YUM for Red Hat-based distros).

### Additional Features

- Configuration and Customization: Tools for adjusting system settings, user accounts, and security options.
- Community Support: Many distributions have active communities that provide assistance and contribute to development.

## Types of Linux Distributions

Linux distributions cater to a wide range of users and purposes, including:

| Type            | Examples                                       |
| --------------- | ---------------------------------------------- |
| General-purpose | Ubuntu, Fedora, Linux Mint, Pop_os             |
| Server-focused  | Red Hat Enterprise Linux, CentOS               |
| pen-test        | Kali Linux, Parrot, backbox, athena os, pentoo |
| Lightweight     | Puppy Linux, Lubuntu                           |
| gaming          | Cachy os, Bazzite, Nobara                      |
| privacy         | tails, qubes os                                |
| advanced user   | gentoo, linux from scratch                     |

Each distribution may have its own goals, target audience, and software selection, allowing users to choose one that best fits their needs.

### [[Window manager & Desktop environment]]

A desktop environment (DE) is a complete graphical workspace. It usually includes a window manager, panels or docks, settings tools, file manager, notifications, and bundled applications.

A window manager (WM) controls how application windows appear and behave—such as their size, position, focus, and virtual desktops. A WM can be used alone or as part of a desktop environment. 
### [[Package Manager]]

A package manager is software that automates the process of installing, upgrading, configuring, and removing software packages on a computer system. It simplifies software management by handling dependencies and ensuring that the necessary components are installed correctly.
