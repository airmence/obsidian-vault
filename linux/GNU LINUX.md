Linux is an open-source, Unix-like operating system family based on the Linux kernel, first released on 17 September 1991 by Linus Torvalds. It’s commonly packaged into different Linux distributions (distros) like Ubuntu, Debian, and Fedora, which include the kernel plus extra software and tools

GNU is a comprehensive collection of free software that serves as an operating system or can be integrated with other operating systems. The name stands for “GNU's Not Unix!” and reflects its goal of creating a free, Unix-like system. It include such as Compiler Collection (GCC), core utilities : Basic tools for file manipulation and system management, a Shell (Bash) A command-line interface for interacting with the system.
## [[kernel]]
is the core program of an operating system that stays in memory and controls how software interacts with the computer’s hardware. It also helps manage tasks like scheduling processes, handling device access, and keeping different processes from conflicting.

## [[Distribution]]
often called a "distro," is a complete operating system built around the Linux kernel, which includes various software packages, system libraries, and a package management system to provide a user-friendly computing environment like a Window manager & Desktop environment or it can be used complety without it. Distributions cater to different user needs and purposes, ranging from general desktop use to specialized tasks.

## [[Terminal, Shell, and Terminal Emulator]]
A computer terminal is a device or software that lets users send commands to and receive outputs from a computer system, typically using a keyboard for input and a screen for output. Early terminals were hardware like teletypewriters, while modern ones are often software emulators such as Linux Terminal or PuTTY.

## [[Linux networking]]
refers to the tools and configurations that allow Linux systems to communicate over networks using protocols like TCP/IP, DHCP, and IPv4/IPv6, managed via the Linux kernel and command-line tools such as ip, ifconfig, and iptables.

## [[everything file]]
In Linux everything is a file and it organizes files in a single, hierarchical tree with the root directory at the top, represented by a forward slash (/). Everything, including devices and directories, is treated as a file under this system.
