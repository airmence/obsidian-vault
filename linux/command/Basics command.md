## move around in the terminal
[[cd]] - change the working directory
[[pwd]] - Display the full filename of the current working directory.
[[ls]] - List directory contents.

## creation and destruction
[[touch]] - Update the access and modification times of each FILE to the current time.
[[mkdir]] - create a directory
[[rm]] - remove files or directories
[[rmdir]] - delete a directory (i stopped here)
[[cp]] - copy files and directories
[[mv]] - move (rename) files
[[ln]] - Make links between files.

## info, manual and tldr
[[info]] - read Info documents
[[man]] - an interface to the system reference manuals
[[tldr]] - Short, practical examples for learning terminal commands.
[[whatis]] - display one-line manual page descriptions
[[apropos]] - search the manual page names and descriptions
[[whereis]] - locate the binary, source, and manual page files for a command
[[which]] - locate a command

## open, read file and pager
[[cat]] - Concatenate FILE(s), or standard input, to standard output With no FILE, or when FILE is read standard input.
[[echo]] - Display a line of text
[[vim]] - Vi IMproved, a programmer's text editor
[[more]] - display the contents of a file in a terminal
[[less]] - display the contents of a file in a terminal

## managing user
 [[useradd]] - create a new user or update default new user information
 [[userdel]]  - delete a user account and related files
 [[usermod]] - modify a user account
 [[passwd]] - change user password
 [[su]] - run a command with substitute user and group ID
 [[whoami]] - Print the current username.
 [[id]]  - Print user and group information for each specified USER, or (when USER omitted) for the current user.
 [[groups]] - Print group memberships for each USERNAME or, if no USERNAME is specified, for the current process
 [[finger]] - user information lookup program
 [[groupadd]] - create a new group
 [[groupdel]] - delete a group

## permissions and access

[[chmod]] - change permissions of a file
[[umask]] - set file mode creation mask
[[chown]] - Change file or directories owner and group

## search & find

[[locate]] - find files by name, quickly
[[find]] - search for files in a directory hierarchy
[[grep]] - print lines that match patterns

## piping & redirecting

[[xargs]] - build and execute commands from standard input
[[tee]] - copy standard input to each FILE, and also to standard output.
[[cut]]  - prints specified byte or field columns from each line of stdin or the input files
[[wc]]  - Print newline, word, and byte counts for each FILE, and a total line if more than one FILE is specified.
[[sed]] - stream editor for filtering and transforming text
[[awk]] - pattern scanning and text processing language
[[sort]]- Display sorted concatenation of all FILE(s). With no FILE, or when FILE is -, read standard input.
[[uniq]] - Report or omit repeated lines.
[[tr]] - Translate or delete characters

## System Resource Monitoring

[[ps]] - report a snapshot of the current processes.
[[top]] - display Linux processes
[[kill]] - send signal to a process
[[killall]] - kill processes by name
[[pstree]] - display a tree of processes
[[lsof]] - list open files
[[free]] - Display amount of free and used memory in the system
[[df]] - report file system space usage
[[du]] - Estimate file space usage
